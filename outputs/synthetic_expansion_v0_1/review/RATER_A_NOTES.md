# Rater A independent AI review notes

This is an AI annotation pass, not an independent human G1 review. I read only the supplied RUBRIC.txt and RATER_A_INPUT.jsonl as task evidence. I did not inspect another rater, owner expectations, mappings, or gold labels. I treated fixture artifacts as stipulated, performed no fixture execution, and used no browsing or external model calls. A local script serialized individually assigned judgments and validated IDs and field ranges; it did not infer labels from lexical features.

All 200 items were reviewed against their actual work products. The binary labels concern the reuse of that work product, not the fraction of the eventual task already completed. Thus an intact empty comparison layout can receive utility 1 even though substantial later work remains. I generally treated an incorrect semantically decisive argument, predicate, or public symbol as material revision even when the edit would be short. Fractions estimate surviving semantic content, not elapsed execution cost, token count, or an empirically measured proportion.

## Methodological problems

- The rubric does not operationalize materiality or specify whether partial salvage makes the entire action useful. A051 retains a closing while changing the approval subject; A132 retains counting structure but changes the severity predicate; A182 retains the addition body but changes its public name. I assigned binary 0 when the action's decisive semantics must change and retained a nonzero fractional value for surviving parts. Other defensible materiality thresholds could disagree.
- Conditional staging can be unresolved without a state observation. A125 contains a 70 F plan and a condition requiring a different current setting, but that item supplies no current reading. I assigned null rather than importing the reading from another item. Its 0.5 fractional value is an uncertainty placeholder, not a probability estimate or evidence that half the command survives. The rubric needs an explicit convention for unknown-condition branches and null utility values.
- Reusable content and procedural compliance differ. A128 stages a departure trigger while the full instruction requires a sensor check before any staging, but the artifact has no execution chronology. Its definition can survive a later sensor check; I labeled that content useful and flagged ambiguity. A075 is a patch when only inspection is wanted: its old constant is informative, but the change itself is outside scope, producing partial salvage rather than an intact useful patch.
- Ancillary work has no defined minimum relevance threshold. A043 and A107 retrieve origin-airport access information while the requested output compares flights. I treated this as reusable travel context, with ambiguity. A046's generic weight sorter can compare backpacks, but weight ranking is not explicitly requested in that completion. The protocol should state whether merely applicable optional work counts.
- A095's runtime filter is independent of topic but introduces an unrequested runtime constraint; no under-90-minute requirement occurs anywhere in that item's full instruction. I rejected its use for the astronomy search rather than treating all generic predicates as reusable. This differs from genuinely unfilled layouts or fields.
- A083's derived growth percentage conflicts with reporting company-stated actual revenue only, while the arithmetic exposes reusable actual operands. The annotation depends on whether the denominator is the result alone or the entire visible equation. I used the entire visible artifact for fractional salvage but rejected the derived output as a completed comparison product.
- Some artifact facts are stipulated without their underlying source documents or input contracts. For example, the exact ERROR-line format and original function semantics are not supplied. I judged the visible functions under their stated task descriptions, with slightly reduced confidence, rather than inventing hidden fixture contents.
- Many repeated scenarios combine near-identical artifacts with reinforcing or reversing continuations. These observations are correlated; nominal item count is not equivalent to 200 independent task families. Strong performance could reflect synthetic regularity rather than generalization to naturally unfolding instructions.
- The rubric contains a human G1 acceptance criterion. Agreement between AI passes on these fictional artifacts cannot establish human agreement, real tool execution reliability, action authorization, or real-world cost savings. Execution classes here predominantly concern preparation, retrieval, and staging; the labels do not establish safe commitment behavior.
