# Observable and internal comparison requirements — development v0.1

Specification only; no new features extracted, probe fitted, baseline certified or frozen endpoint amended.

1. Fix decision stage, exact serialized context and typed candidate before capture. The same prefix-known schema/environment context and candidate are available to all nested models. Do not compare old plain-prefix states with new task-conditioned observable outputs as incremental internal value.
2. Surprisal: independently tokenize each observed prefix; logits[i-1] scores observed token[i]. Retain scored count, NLL sum/mean and first-token-unscored status; singleton mean is null. Produce float64 summaries from canonical FP32 active logits without changing legacy tensors. Pin capture code and run a new bounded bridge against old hidden/logit outputs on the same fixtures/config before any new research capture. Preflight the full actual inputs; overlength blocks the job. New width/config requires G0 validation. Stored last-position logits cannot retrospectively supply full-prefix surprisal.
3. Action probabilities: freeze the typed action inventory, argument canonicalization, null/other/abstain handling, probability event and output interface. A finite closed action-support probability must say it is conditional on that support. Do not rename next-token entropy as action confidence or normalize heterogeneous scores into an unspecified event. This design remains open until the adapter's prefix-known tool schema is available.
4. Argument completeness: encode required/optional slots with present/unknown/ambiguous and prefix-time evidence. Persistence tracks canonical action plus arguments across declared checkpoints, handling aliases and missing observations. Freeze parsers and test suffix-only arguments, target changes and equivalent forms. Never use the true final length as fraction observed.
5. Fair action conditioning: expose the same typed action representation to B0/B1/B2/M. Specify candidate-by-feature interaction capacity for observable and internal models before fitting, not only for M. Freeze model family, regularization treatment, dimensionality limits and equal search budgets prospectively. This is a requirement specification; no replacement classifier is selected here. Preserve the protocol's primary learner and endpoint; any diagnostic alternative must be named separately.
6. Separate snapshots, current cross-layer geometry and ordered temporal features. Include the protocol's within-utterance order-shuffle and trajectory residualization controls. Fit residualization and transforms on fit data only; apply fixed transforms downstream. Snapshot/layer/dimension choices use development-only procedures with equal declared budgets. Do not present current geometry gains as temporal evidence.
7. New comparisons require a separately frozen development design with independent-family sampling/precision assumptions, complete denominators, label versions, outcome-independent grouping, held calibration and reported missingness. Conditional bootstrap interpretation and training/label sensitivities are separate. Existing exposed examples cannot become untouched confirmatory data. Negative results are accepted.

A later gain means predictive value under the defined baselines, learners and resource conditions. Deterministic model states are functions of exact inputs; this does not imply information absent from the full observed context. H2 scientific value remains separate from S1 product benefit.

Readiness decision: source/decision contract, real capture bridge, action outputs, semantic slots, fair interactions and temporal controls are individually required evidence, not boxes satisfied by prose. Human G1 and the confirmatory prohibition remain unchanged.
