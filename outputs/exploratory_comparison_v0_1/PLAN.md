# Frozen exploratory diagnostic comparison plan — v0.1

Scope: private AI-labeled diagnostic, not H2/H3 or the complete preregistered B1/B2/M comparison. Frozen thesis and scientific endpoints unchanged. No foundation-model inference, training, confirmatory extraction or execution of candidate artifacts. Human G1 deferred, not passed. Public adaptation/release admission pending.

This plan is frozen before feature construction or probe fitting. Use all 200 main cases and their original grouped fit/tune/check partitions without rerolling. Preserve the 20 boundary controls, 60 other proposals, all abstentions and all source/checkpoint denominators in their existing artifacts; no new labels for them. This selected proposed-action sample cannot establish end-to-end speculation risk, latency benefit or a causal public/synthetic effect.

Models: prevalence (fit task-weighted prevalence with Laplace-style 0.5 pseudo-count smoothing); D-text (prefix and prefix-known candidate TF-IDF plus shared length/class/lexical cues); D-output (D-text plus available vocabulary-output signals); D-snapshot (D-output plus 64 fixed random projections of hidden-state entry 14); D-multisnapshot (D-snapshot plus 64 projected coordinates each from entries 7,21,28); D-dynamics (D-multisnapshot plus raw-state temporal and cross-layer geometry). Names deliberately do not assert full B1/B2/M implementation. Entry 0 is embedding, entry k corresponds to decoder output k (entry 28 includes final output normalization). Candidate features are shared by all learned models.

Shared numeric features: prefix word/token/character counts, candidate character count, execution class, numeric-token count, trailing preposition/conjunction indicator and terminal punctuation indicator. These are lexical cues, not validated semantic argument completeness. Prefix and candidate TF-IDF encoders each use word unigrams/bigrams, lowercase, max_features=512, min_df=1; fit only on the scenario's usable fit cases. No full instruction, source, ID, split, group or label rationale enters predictor features. No true fraction-observed feature.

Output features use only the current and preceding two independently tokenized completed-word prefixes: entropy (nats), top-1 probability, top-2 probability margin, top-1 token persistence for the last transition, Jensen–Shannon divergence for the last transition, entropy change and three-position mean entropy. They are vocabulary distributions, not action probabilities. No token surprisal is claimed: full observed-token surprisal is unavailable. Strong B1 still needs action probabilities, validated argument completeness and a supported surprisal definition before any H2 interpretation.

Snapshot projection: NumPy PCG64 seed 1729, Gaussian 3584x64 matrix divided by sqrt(64), shared across all four layers. No projection or layer search. Temporal features: for each of entries 7,14,21,28, last-step L2 displacement, cosine continuity, norm of difference between last two displacement vectors (acceleration), and 1-cosine between those displacements (curvature). Cross-layer features: current cosine for pairs (7,14),(14,21),(21,28). Zero vector cosine uses zero with explicit epsilon=1e-12. These geometric diagnostics are not projected action-distribution or lens features. Derived features use float64 on CPU; original FP32 tensors stay unchanged.

All learned models use L2 logistic regression (liblinear, max_iter=2000, seed1729), a diagnostic implementation rather than the preregistered elastic-net primary classifier. Numeric StandardScaler fits on fit cases only. C grid=[0.01,0.1,1,10], selected by lowest task-averaged tune NLL with smaller-C tie break. Each training task has equal total sample weight. No check-based tuning, layer selection, threshold fitting, dimensionality search or outcome-driven feature changes. Preserve warnings and nonconvergent fits; do not use nonconvergent candidates. No refit after tune selection.

Five fixed label scenarios, each independently refitted with the same feature definitions/grid: (1) current resolved labels (8 unresolved not scored, still preserved/predicted); (2) replace only the 65 prior-overlap labels with their original prior labels; (3) resolved cases excluding all ambiguity-flagged cases, explicitly a diagnostic selection sensitivity; (4) all eight current unresolved set to zero as a pessimistic stress assumption; (5) all eight set to one as the opposite stress assumption. Original labels never change. Scenarios may change denominators and are not directly interchangeable prevalence estimates. Evaluate both sources separately as descriptive slices only.

Report per-case predictions, fit/tune/check counts, selected C and all grid losses/warnings; task-averaged NLL and Brier on tune/check. For the current-resolved check sample only, report paired task-mean NLL gains D-text→D-output, D-output→D-dynamics and D-multisnapshot→D-dynamics, with 2,000 group-cluster bootstrap replicates (seed1729), preserving template-connected tasks. These intervals are exploratory, not the frozen confirmatory endpoint. The check split has just two negative cases; no low-risk policy, reliable risk estimate or efficacy/generalization claim follows.

Validation: compare entropy/JS/cosine/displacement against analytic toy cases; verify each source tensor hash and contract before deriving features; require exact 200-row coverage and finite features; preserve feature/plan/code hashes before fitting; test that changing check labels does not alter C selection or predictions; replay metric calculation from saved predictions independently.

Resources: CPU only. Feature jobs contain at most 10 cases (30 prefix reads before within-job deduplication), max4 workers x2 CPUs/8GiB, 600s per job, zero retries. Fit job 2 CPUs/8GiB/600s, zero retries. Use read-only tensor volume and pinned torch2.5.1, numpy1.26.4, scipy1.14.1, scikit-learn1.5.2. Save every attempt and failure. No metered cost asserted. Revisit human G1 after this first bounded comparison/sensitivity report; it remains a hard gate before confirmatory labeling/freeze.
